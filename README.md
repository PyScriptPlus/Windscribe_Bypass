# Windscribe_Bypass

# How to use:
1.The first step is to log out of the existing Windscribe account you are currently using.

2.The second step is to end the task for the Windscribe program.

3.The third step is to open PowerShell as an Administrator and execute the `bypass.ps1` file within the current project directory.
An easier method: You can simply run the `run.bat` file as an Administrator.

You're all set!
Go ahead, create an account, and enjoy.
